# No PCB fabrication

LAUNCHPAD uses jumper wiring and a breadboard or hand-soldered perfboard buzzer driver. No PCB layout exists, so there are no genuine Gerbers, drill files, pick-and-place files or PCB fabrication ZIP to export. A dummy Gerber ZIP would be misleading. The KiCad schematic, netlist, PDF and wiring CSV are the electronic source package for this build.
